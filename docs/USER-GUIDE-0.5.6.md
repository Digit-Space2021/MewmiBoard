# 喵咪小黑板 · Mewmi Board 0.5.6 使用说明

## 连接Agent

管理员先检测并保存Agent专用服务端口，默认20269，必须与NAS网页和其他服务正在使用的端口不同。普通用户不需要设置端口。支持HTTP和HTTPS、IP和可达域名。地址框显示到端口，已有代理子路径仍保留。

本地连接：填写Agent能访问的NAS网页登录地址和Agent服务入口。远程连接：分别填写NAS远程网页登录地址、由管理员配置的Agent服务端口代理地址。内网访问时不会替你把内网地址填入远程栏，请填写真实可用的远程地址。FN Connect可用于打开授权网页，不能单独作为独立后台接口。

启用对应方式后，一键生成技能包，交给Agent；打开它生成的NAS授权链接，登录并选择能力，把一次性授权码发回Agent。只有实际读取成功才算连接完成。保持Agent运行并授予接收提醒权限才会持续接收提醒，创建内容仍需逐次确认。

改端口须确认撤销全部旧连接，检测或保存失败会保留旧连接。仅本次确实失效的用户收到重置通知。从未连接Agent的用户不收到这些通知。停用某种方式仅通知使用该方式且仍有效的连接用户，另一种方式不受影响；重新开启时通知此前受影响的用户，说明原授权可继续用还是需要重新生成技能包并授权。通知在消息中心保留，再按本人推送/双向渠道和免打扰规则发送；队列不等于平台已送达。

已连接列表按本人及NAS访问地址归属；撤销后短暂显示“已撤销”再移除。旧记录缺NAS地址时以旧连接显示，重新授权后精确归类。刷新图标在标题旁，支持深浅主题。

## 消息推送

保存过的配置以遮罩显示，未填写的项目显示填写提示。点击眼睛可短时查看本人保存值，再点隐藏；失焦、切换渠道、关闭设置或15秒后自动隐藏。重新输入不会因为点眼睛而保存，只有“保存”才生效。未修改的保存字段会保留，主动清空的字段按空值保存。解绑删除本人的该渠道配置。

开启外部推送与相应渠道，再按需发送测试。普通事项推送不再附加聊天回复操作说明，原生双向聊天的已有确认与反馈能力仍保留。

## 日历与页面

日历可直接按日/周/月导出当前周期，也可Ctrl点击或手机长按选择日期；全选和退出在导出左侧，跨页保留选择，跨天事项不重复。先预览再导入ICS，无法完整支持的规则会明确提示。

“随时记一下”展开或收起后，页面末条内容可滚到框上方；手机菜单打开时隐藏快捷框并保留草稿。今日状态与置顶分别操作。关于页保留新手引导、鸣谢、外观、隐私和许可，字号已协调。

## 安装和数据

面向从0.4.5升级的用户，安装最新架构对应FPK即可，应用自动按顺序迁移数据，无需依次安装中间版本。安装前停止应用并备份NAS持久数据与私有密钥；源码备份不是数据库备份。旧版回退需恢复匹配的数据备份。更新后若浏览器资源仍旧，请刷新页面。
